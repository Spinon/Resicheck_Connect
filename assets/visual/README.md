# Assets visuais

Guardar referências aprovadas e originais editáveis. A direção está em [DIRECAO-VISUAL.md](../../docs/product/DIRECAO-VISUAL.md); exemplos v0.2 aprovados e verde escolhido como padrão. Assets finais ainda não foram incorporados e a aprovação visual não substitui testes funcionais/acessibilidade.

Exportações para revisão ficam em `output/entregas/<lote>/assets-visuais/`, com dimensões, plataforma e versão no nome. Usar dados sintéticos nas telas. O usuário autorizou aproveitar o logo ResiCheck se encontrado; verificar origem/variante antes de copiar. Esta tarefa não afirma tê-lo localizado nem autoriza copiar outros assets.
