# Aplicativo futuro

Pasta reservada à base compartilhada Android/iOS. Nenhum app foi inicializado aqui.

Proposta inicial: React Native com Expo e TypeScript. Criar projeto com versão estável compatível, lockfile e perfil de APK de teste após consolidar a decisão e obter autorização para instalações necessárias. Não executar geradores com `latest` sem verificar previamente versões e requisitos.

Primeira fatia: abrir no Android, alternar entre uma empresa e um paciente sintéticos e percorrer uma conversa demonstrativa. Mocks precisam estar identificados como demonstração no ambiente de teste; sem fingir persistência, envio ou autenticação real. Web pode ajudar a iterar, mas o aceite da fatia exige Android.
